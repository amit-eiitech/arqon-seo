# Security Policy

## Supported Versions

Security fixes are applied to the latest release. Older releases may require upgrading to the latest version.

## Reporting a Vulnerability

Please report vulnerabilities privately through the repository's GitHub Security Advisories page. If private reporting is unavailable, open an issue requesting a private communication channel. Do not publish an unpatched vulnerability or sensitive reproduction details publicly.

Please include:

- A description of the affected behavior
- The package and PHP/Laravel/Filament versions
- Steps to reproduce
- A proof of concept, if available
- Potential impact
- Suggested remediation, if known

You will receive an acknowledgement as soon as the maintainers can respond. After the issue is confirmed, maintainers will develop and test a fix and coordinate disclosure and release timing with the reporter.
